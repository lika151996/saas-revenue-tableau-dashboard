# SaaS Revenue Dashboard (Tableau)

Interactive Tableau dashboard for SaaS revenue analysis and business performance tracking.

## Project Overview

This dashboard analyzes:
- Total Revenue
- Paid Users
- ARPPU (Average Revenue Per Paid User)
- Revenue trends over time
- Revenue by product
- Revenue by location

The project also includes bonus visualizations such as:
- Revenue distribution box plot
- Revenue share by location over time

## Dashboard Features

- Interactive filters
- Dashboard actions
- KPI cards
- Dual-axis charts
- Heatmaps
- Time-series analysis

## Tools Used

- Tableau Public
- Data Visualization
- Dashboard Design
- Calculated Fields
- Table Calculations
